## 2. 후보 3안 비교

### 🥇 후보 A — 선택적 예측에서 "거절"의 임상적 역효과 (강력 추천)

**한 줄**: 저신뢰 입력을 거절하는 관행이 피부 병변 도메인에서는 악성을 우선적으로
버리므로, 거절 대신 경고로 전환해야 한다.

| 항목 | 평가 |
|---|---|
| 신규성 | **높음** — "당연히 좋다"고 여겨지는 설계에 대한 도메인 반례 |
| 데이터 보유 | **이미 있음** — 홀드아웃·OOD 기준값 JSON 커밋 완료 |
| 추가 실험량 | 중 (§4-1, 4-2) — 1~2주 |
| 재현성 | **매우 높음** — 홀드아웃 목록·OOD 생성기 모두 결정적, 저장소에 있음 |
| 위험 | 추가 baseline 비교 없이는 "임계값 하나 바꾼 얘기"로 읽힐 수 있음 → §4에서 해소 |

**왜 이게 통하는가.** 심사위원이 이 분야에서 가장 많이 보는 문장이 "신뢰도가 낮으면
의사에게 이관한다"이다. 이건 **거절이 난이도를 따라간다**는 전제 위에 서 있는데,
우리 측정은 그 전제가 이 도메인에서 깨진다는 걸 보여준다 —
**애매한 쪽에 악성이 몰려 있어서, 애매한 것부터 걷어내면 암부터 걷어낸다.**

여기에 두 번째 칼이 붙는다. **거절 임계값은 원래 맡기로 한 일(비병변 입력 차단)조차
못 한다.** 0.35에서 비병변 사진의 79.6%가 그냥 통과해 병명을 받았고, 정상 피부 391장 중
137장(35.0%)이 악성·전암 판정을 받았다. 단색 회색 사각형이 확신도 89.6%로,
체크무늬가 **100.0%**로 `inflammatory` 판정을 받는다.

> 즉 **비용은 확실하고(암을 놓침) 효과는 없다(OOD를 못 막음).** 이 비대칭이 논문의 축이다.

**논문에서의 프레이밍** — 이건 단순한 임계값 튜닝이 아니라,
선택적 예측(selective prediction)의 평가 방식 자체에 대한 지적으로 올려야 한다.

> 기존 연구는 거절의 **효용**을 거절되지 않은 표본의 정확도(selective accuracy)로 잰다.
> 그 지표는 어려운 문제를 풀지 않고 얻은 점수라 항상 올라간다.
> 임상에서 중요한 건 **같은 100명 중 실제로 몇 명의 암을 찾았는가**이고,
> 그 지표로 재면 부호가 뒤집힌다.

이 한 문단이 논문의 핵심 주장이 된다.

### 🥈 후보 B — 데이터셋 혼합 학습에서 발생하는 "출처 단서" 지름길 학습

**한 줄**: 서로 다른 촬영 방식의 데이터셋을 클래스별로 다르게 섞으면, 모델이 병변이
아니라 **촬영 장비를 분류**하게 되고, 그 클래스가 OOD 쓰레기통이 된다.

우리 관찰:

- `inflammatory` 클래스만 SCIN(일반 스마트폰 사진)으로 학습 → 홀드아웃에서 **99.49%**
  (전체 클래스 중 최고)
- 그런데 병변이 전혀 없는 합성 이미지 152장 중 123장이 통과, **그중 92장이 `inflammatory`**
- 단색 회색 사각형 89.6%, 체크무늬 100.0% 확신도로 `inflammatory`

→ **99.49%는 "염증을 잘 안다"가 아니라 "더모스코피가 아닌 것을 안다"일 가능성이 높다.**

| 항목 | 평가 |
|---|---|
| 신규성 | 중~높음 — shortcut learning의 구체적 사례, 국내 학회에서 드묾 |
| 데이터 보유 | 부분적 — 정황 증거는 있으나 **인과를 보이는 실험이 없음** |
| 추가 실험량 | **큼** — 출처만 맞춘 대조 실험, Grad-CAM 분석, 재학습 필요 |
| 위험 | 재학습이 들어가면 마감 안에 못 끝낼 수 있음 |

**판정: 단독 논문으로는 시간이 부족하다. 후보 A의 한 개 절(3~4문단)로 넣는다.**
"왜 임계값이 OOD를 못 막는가"에 대한 원인 설명으로 자연스럽게 붙고, 그 자리에서는
정황 증거만으로도 충분히 기능한다.

**한 줄**: 대기실 예비분석부터 원내 프린터 출력·비로그인 문서 열람까지, 클라우드

4. **종이 QR + 생년월일 2요소 비로그인 열람** — 토큰 단위 레이트리밋

| 항목 | 평가 |
|---|---|
| 신규성 | 중 — 개별 요소는 알려진 기법, **조합과 제약 조건이 기여** |
| 데이터 보유 | **완비** — 추가 실험 0 |
| 추가 실험량 | **없음** (원하면 처리량 측정만 추가) |
| 위험 | "만들었습니다" 논문으로 읽히면 약함 → 정량 평가가 최소 1개는 필요 |

## 4. 논문이 되려면 지금 추가로 해야 할 실험

현재 데이터만으로도 주장은 성립한다. 하지만 심사에서 **"임계값 하나 바꾼 것 아니냐"**,
**"MSP 말고 다른 방법을 써봤냐"**는 질문이 반드시 나온다. 그걸 미리 닫는 게 아래 3개다.

기존 하네스(`fastapi/tests/evaluate.py`)가 이미 임계값 곡선과 OOD 평가를 돌리므로,
**전부 그 파일에 옵션을 추가하는 수준**이고 재학습은 필요 없다.

### 4-1. 불확실성 추정 방법 비교 (필수 · 난이도 낮음 · 반나절)

지금은 **MSP(Maximum Softmax Probability)** 하나만 쓴다. 이건 OOD 탐지에서 가장 약한
baseline으로 알려져 있어서, "약한 방법으로 재 놓고 안 된다고 결론 내렸다"는 반박이 가능하다.
**같은 모델·같은 홀드아웃에서 점수 함수만 갈아끼워** 네 가지를 비교한다.

| 방법 | 구현 난이도 | 필요한 것 |
|---|---|---|
| MSP (현재) | — | 이미 있음 |
| **MaxLogit** | 매우 낮음 | softmax 전 logit의 max — 1줄 |
| **Energy score** | 낮음 | `-logsumexp(logits)` — 1줄 |
| **Temperature scaling + MSP** | 낮음 | 홀드아웃 일부로 T 보정 |

→ **기대 결과**: 네 방법 모두 "비병변 통과율이 받아들일 수 없는 수준"이라면,
주장이 **"MSP의 한계"가 아니라 "이 문제는 점수 함수로 풀리지 않는다"**로 강해진다.
반대로 Energy가 확실히 낫다면 그것도 그것대로 논문이 된다 — **어느 쪽이 나와도 결과가 있다.**

### 4-2. 정식 선택적 예측 지표 도입 (필수 · 난이도 낮음 · 반나절)

지금 표는 "임계값 0.35/0.45/0.60/0.95"의 이산 점들이다. 논문 심사에서는 표준 곡선을 원한다.

- **Risk–Coverage 곡선** — 커버리지(답을 준 비율) 대 위험(오답률)
- **AURC** (Area Under Risk-Coverage curve) — 한 숫자로 요약
- **위험군 한정 Risk–Coverage** — 오답을 "악성→양성 오분류"로 정의한 버전 ← **이게 핵심**

두 곡선을 겹쳐 그리면 우리 주장이 그림 한 장이 된다:
**일반 오답 기준으로는 거절이 이득처럼 보이지만, 악성 누락 기준으로는 손해다.**

> 이 그림 한 장이 논문의 Figure 1이다. 여기에 모든 게 들어 있다.

### 4-3. "경고 밴드가 값을 한다"의 정량화 (권장 · 이미 거의 있음)

현재: 경고 밴드(14.35%) 안 정확도 57.3% vs 밖 88.3%, 전체 오답의 38.0%가 밴드 안 → **2.6배 농축**.

논문에서는 여기에 한 줄만 더 붙이면 된다:

- 밴드 안/밖 **악성 누락률**을 따로 계산 → "경고를 보고 의사가 한 번 더 보면 무엇을 건지는가"
- 커버리지 대비 **오답 검출 효율(lift)** 곡선

### 4-4. 하지 않아도 되는 것 (시간 아끼기)

| 하고 싶어지는 것 | 왜 안 해도 되는가 |
|---|---|
| 모델 재학습 / 더 큰 백본 | 논문 주장이 모델 성능에 관한 게 아니다. 오히려 초점이 흐려진다 |
| 전용 OOD 판별기 구현 | **"향후 연구"로 남긴다.** 이게 답이라는 것만 논증하면 충분하다 |
| 사용자 평가(의사 대상 설문) | IRB·모집 문제로 마감 안에 불가능 |
| 새 데이터셋 추가 수집 | 홀드아웃 고정이 깨진다 — 지금까지 기준값과 비교가 무효가 됨 |

## 5. 논문 구조 (4페이지 배분)

> KSC 학부생/주니어 논문은 통상 4페이지 내외다. **정확한 페이지 제한은 §1에서 확인한
> 공식 양식 파일 기준으로 맞춘다.**

| 절 | 분량 | 내용 |
|---|---|---|
| **1. 서론** | 0.5p | AI 보조 진단에서 "저신뢰 거절"이 표준 관행임 → 우리는 그게 역효과임을 보인다. 기여 3줄 명시 |
| **2. 관련 연구** | 0.4p | 선택적 예측 / OOD 탐지 / 의료 AI 신뢰도. **짧게.** 우리가 반박하는 전제를 세우는 게 목적 |
| **3. 시스템 및 실험 설정** | 0.7p | EfficientNet-B0 8클래스, HAM10000+PAD-UFES-20+SCIN, **고정 홀드아웃 2,857장**, OOD 543장 생성 절차 |
| **4. 실험 결과** | **1.6p** | 4-1 임계값 양쪽 비용 / 4-2 Risk-Coverage(Fig.1) / 4-3 점수 함수 비교 / 4-4 경고 밴드 효용 |
| **5. 논의** | 0.5p | 왜 이런 일이 생기는가 — 출처 단서 지름길 학습(후보 B) + `inflammatory` 쓰레기통 현상 |
| **6. 결론 및 향후 연구** | 0.3p | 거절→경고 전환 권고 / 전용 병변 판별기가 답이라는 방향 제시 |

### 기여(contribution) 3줄 — 서론 끝에 그대로 넣는다

1. 피부 병변 분류에서 **저신뢰 거절이 악성 재현율을 체계적으로 떨어뜨림**을
   고정 홀드아웃 2,857장으로 실측했다 (89.3% → 86.3%).
2. 거절 임계값이 **본래 목적인 비병변 입력 차단에는 작동하지 않음**을
   재현 가능한 OOD 세트 543장으로 보였다 (0.35에서 79.6% 통과).
3. 같은 임계값을 **경고로 전환**하면 재현율 손실 없이 오답의 38.0%를 상위 14.35%
   구간에 표시할 수 있음을 보이고, 실제 시스템에 적용했다.

## 6. 심사에서 나올 질문과 답변 준비

| 예상 질문 | 준비된 답 |
|---|---|
| **"홀드아웃이 학습에 안 쓰였다는 보장이 있나?"** | 이 모델에 대해서는 사후 복원이라 확정 못 함. **다만 상한을 안다** — 학습분에서도 84.84%밖에 못 맞히므로 오염으로 인한 과대평가는 최대 1%p. 다음 모델부터는 `holdout.csv`가 학습에서 제외되도록 노트북이 강제 (`ALLOW_NEW_HOLDOUT=False`). **이 한계를 논문에 명시적으로 쓴다** |
| "MSP는 원래 약한 baseline 아닌가" | §4-1로 답한다. 4종 비교 |
| "OOD 세트가 합성인데 현실적인가" | `normal_skin` 391장은 **실제 PAD 홀드아웃 사진의 모서리 크롭**이다. 키오스크에서 실제로 일어나는 오촬영(빈 팔뚝)에 가장 가깝고, 이 갈래가 가장 어렵다는 것도 측정됨 |
| "표본이 한 도메인(피부)뿐이다" | 인정하고 한계로 명시. 대신 **출처별 3분할**(더모스코피/스마트폰/일반사진)로 조건 차이를 보인다 |
| "경고가 실제로 의사 판단을 바꾸는가" | **아직 모른다.** 사용자 평가는 향후 연구로 명시. 이걸 안다고 우기면 안 됨 |

> **마지막 항목이 중요하다.** 학부 논문에서 가장 흔한 탈락 사유는 신규성 부족이 아니라
> **검증하지 않은 것을 검증한 것처럼 쓰는 것**이다. 우리는 이미 저장소 문서 전체에서
> "확정하지 못했다"를 그대로 적는 문화가 있으니, 그 톤을 논문에도 그대로 가져간다.

## 7. 쓰지 말아야 할 것 (감점 요인)

- ❌ **"정확도 83.86%를 달성했다"를 주된 기여로 내세우기** — 이 숫자는 SOTA가 아니고,
  그 경쟁에 들어가는 순간 진다. 우리 기여는 정확도가 아니다
- ❌ Grad-CAM 구현을 신규성으로 주장 — 널리 알려진 기법이다. **시스템 설명으로만** 언급
- ❌ "의료진의 진단을 대체한다" 류의 표현 — 반드시 보조(assistive)로 서술
- ❌ Gemini/LLM 처방 코멘트를 논문 주제로 — 검증이 없어 방어 불가. **아예 빼는 게 낫다**
- ❌ 환자 데이터·KCD/약품 마스터 원본 관련 서술 — **기업 멘토 사전 확인 없이는 쓰지 않는다**
