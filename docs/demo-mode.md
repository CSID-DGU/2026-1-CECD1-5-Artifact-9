# 로그인 없이 데모 체험

로그인 화면의 **로그인 없이 데모 체험하기**를 누르면 계정 없이 서비스 전체 흐름을 직접 눌러 보며 따라갈 수 있다.
흐름은 접수 → 키오스크 사전 분석 → 진료·AI 분석 → 상병·약품·AI 처방 코멘트·처방 → 조회 → 증명서 발급 → 대기실 현황판이다.
배포 구성과 상관없이 늘 켜져 있다.

## 어떻게 도는가

- **화면은 운영과 같다.** 접수·진료·조회·증명서·키오스크·현황판 화면을 그대로 쓴다. 데모를 위해 따로 만든 화면은 없다.
- **실제 서버로는 아무것도 가지 않는다.** 데모일 때만 `/api` 요청을 브라우저 안의 가짜 백엔드(`frontend/src/demo/backend.ts`)가 받는다(`installDemoFetch.ts`가 `fetch` 하나만 가로챈다). 화면은 CloudFront, API 는 ALB 처럼 출처를 나눈 배포(`VITE_API_BASE_URL`)에서는 그 API 출처의 `/api` 도 가로챈다.
  - 로그인 없이 들어온 사람이 운영 DB 의 실제 환자 기록을 보거나 남길 수 없다.
  - 상태 전이, 발급 조건, 오류 문구는 실제 백엔드를 따랐다(`Visit`·`VisitService`·`CertificateService` 등).
- **이 탭에서만 돈다.** 데모 표시와 가상 데이터는 `sessionStorage`에 있다.
  - 탭을 닫으면 끝난다.
  - 같은 브라우저 다른 탭의 실제 로그인(localStorage)은 읽지도 쓰지도 않는다. 접수 데스크 노트북에서 누가 데모를 눌러도 직원 탭은 그대로다.
  - 데모 탭에서 실제 계정으로 로그인하면 데모가 끝나고 실제 서버로 간다.
- **가상 데이터** (`demo/seed.ts`): 이름과 전화번호(010-0000-xxxx)는 모두 지어낸 것이다.
  - 가상 환자 8명
  - 지난 진료 6건: 사진, AI 분석, 처방, 일부 증명서까지
  - 오늘 대기 2건
- **업로드 대신 사진 선택.** 키오스크와 진료 화면의 '파일 선택'이 미리 골라 둔 사진(얼굴 20·피부 병변 20, `public/demo/presets`)을 고르는 창을 연다.
- **AI 결과는 미리 돌려 둔 것이다.** 사진 40장을 운영과 같은 모델로 돌린 결과와 히트맵이다(`public/demo/results`, `demo/data/presets.json`). 확대 재판정도 포함된다.
- **AI 문장은 미리 써 둔 문장이다.** 키오스크 참고 소견, AI 처방 코멘트, 증명서 초안은 질환별로 준비한 문장이다(`demo/cannedText.ts`).
  - 실제 LLM 을 부르지 않는다.
  - 화면의 모델 이름 자리에 '데모 응답'이 뜬다.
- **출력하지 않는다.** 감열지 출력 버튼을 누르면 "데모에서는 실제로 출력하지 않습니다"가 뜬다. 증명서 A4 인쇄·PDF 는 브라우저 기능이라 된다.
  - 데모로 발급한 증명서의 비고 칸에는 "데모 체험용 문서 — 법적 효력이 없습니다."가 찍힌다.
- **KCD·약품 검색은 피부과 범위만** 들어 있다(KCD 631개, 약품 912개, 원본 엑셀에서 추림).
- **데모 체험 가이드**: 화면 왼쪽 아래에 지금 할 일 하나와 이동 버튼이 뜬다. 가짜 백엔드 기록을 보고 진행을 저절로 체크한다.
  - '키오스크 열기'는 같은 탭에서 키오스크 화면을 연다. 데모는 이 탭 안에서만 돌아, 접수 QR 을 다른 휴대폰으로 찍으면 실제 서버로 간다.

## 데모 자료 다시 만들기

모델 가중치가 바뀌면 결과를 다시 만든다. 사진과 설명은 그대로 두고 결과만 새로 쓴다.

```bash
cd fastapi && INTERNAL_API_SECRET=local python ../scripts/demo/make_demo_results.py   # 결과·히트맵
python scripts/demo/make_demo_reference.py                                             # KCD·약품(openpyxl 필요)
```

## 고칠 때 보는 곳

| 하고 싶은 것 | 파일 |
|---|---|
| 가상 환자·지난 진료 바꾸기 | `frontend/src/demo/seed.ts` |
| 새 API 를 데모에서도 받기 | `frontend/src/demo/backend.ts` (`route`) |
| 안내 단계·문구 | `frontend/src/demo/DemoGuide.tsx` |
| AI 문장 | `frontend/src/demo/cannedText.ts` |

새 화면이 새 `/api` 경로를 부르면 `backend.ts`에도 넣어야 한다. 빠뜨리면 데모에서 그 화면만 "데모에서 지원하지 않는 요청입니다"(404)가 뜬다. 운영에는 영향이 없다.
