## 🚀 What's New

### AI Server (FastAPI)
- 태스크 두 개 — `skin_lesion`(8종, 기본) · `facial`(6종), 요청의 `task` 로 고른다
- LayerCAM(`blocks.4` · `blocks.2`) 히트맵으로 통일, 확대 히트맵(최대 3장), 확신이 낮을 때 확대 영역으로 재판정
- `GET /health/ready` — 모든 태스크 모델이 로드돼야 200 (로드 밸런서 상태 검사)
- 공유 비밀(`X-Internal-Secret`) 없는 추론 요청 거절, 사진으로 열 수 없는 입력은 500 대신 400

### Backend (Spring Boot 3.5.14 / Java 21)
- Flyway 마이그레이션 도입 (V1 ~ V13)
- 키오스크 · 예비분석(`preliminary_analysis`) · 증명서(`certificate`) · QR 문서 공유 토큰 · 출력 작업 큐 · 텔레그램 알림
- 직책별 권한 — `@StaffAccess` · `@MedicalAccess` · `@DoctorAccess` (진단 확정 · 처방 · 서술형 서류는 의사)
- `LlmGateway` — 공급자 대체 · 요청별 시간 예산 · 잘린 응답 · JSON 검증, Claude(Haiku 5.5) 보조
- 잘못된 요청은 500 대신 400 · 404 · 405 · 415
- ALB 뒤 배포 대비 — CORS preflight, `GET /api/health`, 프록시 헤더, EC2 인스턴스 역할 자격 증명

### Frontend (React 19 + Vite 8 + Tailwind v4)
- 키오스크(`/kiosk/{token}`) — 본인 확인 · 촬영 대상 선택 · 인쇄물 자동 자르기 · 예비분석
- 대기 현황판(`/waiting`), QR 공개 문서(`/d/c/{token}` · `/d/v/{token}`)
- 진료: 예비분석 카드 · 히트맵 보기 · 확대 히트맵 · 접수번호 검색 · 접수취소
- 증명서: AI 초안 · 발급 · 재발급 · 무효 · 인쇄
- 로그인 없는 데모 모드, `VITE_API_BASE_URL` 로 API 출처 분리

### Infra / CI/CD
- GitHub Actions — CI(백엔드 테스트 · 프론트 린트/빌드 · FastAPI 빌드/기동), Deploy(self-hosted, `DEPLOY_TARGET=elb`), Deploy Web(S3 + CloudFront), Deploy AI(ECR + 인스턴스 새로 고침)
- AWS 콘솔 실습 가이드(`docs/aws-elb-asg-guide.md`), 아키텍처 · 시나리오 · 비용 비교(`docs/architecture/`)

## 📡 API 추가/변경

```http
GET    /api/health                                        # 로드 밸런서 상태 검사
DELETE /api/v1/visits/{id}                                # 접수취소 (처방 전까지)
POST   /api/v1/visits/{id}/kiosk-token                    # 키오스크 QR 토큰
GET    /api/kiosk/session/{token}                         # 키오스크 본인 확인
POST   /api/kiosk/session/{token}/analyze                 # 키오스크 예비분석
POST   /api/kiosk/session/{token}/comment                 # 키오스크 참고 소견
GET    /api/v1/visits/{visitId}/preliminary               # 진료실에서 보는 예비분석
GET    /api/v1/visits/{visitId}/analysis/heatmap/crops/{rank}
POST   /api/v1/visits/{visitId}/certificates/draft        # 서류 AI 초안
POST   /api/v1/visits/{visitId}/certificates              # 서류 발급
POST   /api/v1/certificates/{id}/reissue | /void
GET    /api/public/documents/certificate/{token}          # QR 문서 (+ POST /verify 생년월일)
POST   /api/v1/visits/{visitId}/print/ticket | /print/visit-summary
GET    /api/v1/print/jobs/next                            # print-agent 출력 작업
```

전체 API 스펙은 Swagger UI(`/swagger-ui/index.html`)에서 확인할 수 있다.

## ⚠️ Known Limitations

- 백엔드와 DB 는 아직 EC2 한 대 — 백엔드 오토스케일링 · RDS Multi-AZ 는 다음 단계(`docs/architecture/05-scenario-b-scale-out.png`)
- AI 분석은 동기 호출이라 요청이 한꺼번에 몰리면 늦어질 수 있다 — SQS 큐 방식은 다음 단계(`06-scenario-c-queue.png`)
- 얼굴 모델은 학습 사진과 다른 실사진에서 정확도가 크게 떨어진다(SCIN 257장 Top-1 27.2% · Top-5 92.2%) — 키오스크에서는 참고용으로만 보여 준다
- 증명서 서식은 연구 · 데모용이며, 실제 사용 전에 법적 효력 검토가 필요하다
